# PhotoConnect

PhotoConnect là nền tảng kết nối khách hàng với nhiếp ảnh gia, hỗ trợ tìm kiếm photographer, xem portfolio, đặt lịch chụp, trao đổi và quản lý booking.

## Công nghệ dự kiến

- Java 26
- Spring Boot / Spring MVC
- JSP / JSTL
- Bootstrap
- JPA / Hibernate
- MySQL / PostgreSQL
- Apache Tomcat 10.1
- Maven
- JWT
- WebSocket
- Cloudinary

## Đối tượng sử dụng

### Khách hàng
- Đăng ký và đăng nhập
- Tìm kiếm nhiếp ảnh gia
- Xem portfolio và bảng giá
- Đặt lịch chụp
- Theo dõi trạng thái booking
- Chat với nhiếp ảnh gia
- Đánh giá sau khi hoàn thành

### Nhiếp ảnh gia
- Quản lý hồ sơ cá nhân
- Quản lý portfolio
- Tạo các gói dịch vụ
- Nhận hoặc từ chối booking
- Quản lý lịch làm việc
- Chat với khách hàng

### Quản trị viên
- Quản lý người dùng
- Duyệt tài khoản nhiếp ảnh gia
- Quản lý booking
- Theo dõi hoạt động hệ thống
