# Contributing

## Branch chính
`main`

## Branch theo chức năng
- `feature/authentication`
- `feature/photographer-profile`
- `feature/booking`
- `feature/chat`
- `feature/admin`

## Commit message gợi ý
- `Initial project setup`
- `Add User entity`
- `Add login functionality`
- `Create photographer profile`
- `Implement booking creation`
- `Add WebSocket chat`
- `Fix booking validation`

## Quy trình cơ bản

```bash
git add .
git commit -m "Mô tả thay đổi"
git push
```

## Quy tắc
- Không commit password
- Không commit API secret
- Không commit JWT secret
- Không commit thư mục `target/`
- Commit theo từng chức năng nhỏ
- Cập nhật tài liệu khi chức năng thay đổi
